## Build

Provide a dedicated cacheable shell for local play with explicit static dependency precaching and version compatibility. Keep online authenticated pages/API responses outside shell caches. Stage worker updates so active local matches retain their runtime; route prepared offline launches to the local shell without requiring an online session refresh.

## Acceptance

- [ ] After preparation, a production build cold-launches from a new browser process with the network disabled, loads its JS/CSS/fonts/worker and can access installed packs.
- [ ] Signed-in collection/deck/admin pages, auth redirects, API bodies and secrets are never placed in the offline shell cache; unrelated online routes preserve current auth behavior.
- [ ] Install/update failure leaves a working previous shell, incompatible shell/pack pairs are refused, and active matches are not forcibly switched by skipWaiting/clients.claim.
- [ ] Run focused scenario checks plus `npm run typecheck`, `npm run lint`, `npm test` and `npm run build` before finalizing code.
