## Problem
Tiny Fish reviewed the signed-in production Decks, leader selection, deck detail and Arena setup UI on 15 October 2026: https://agent.tinyfish.ai/runs/d0926c12-fd3d-4fe3-9d1e-adb770709416 . Long deck names (Cooler Armored Squadron, Universe 2 Maiden Squadron, multiple Vegito decks) are cut off, descriptions are hidden in deck editing, and the opponent dropdown lists roughly 19 decks without search. Decks had 28 entries with no name/strategy search; leaders offered only game/colour filtering.

The owner requests a full-screen phone creation wizard so each side's deck gets space for its name and description. Desktop keeps both sides visible. Add meaningful filters before browsing and keep the opponent list short.

## Build
- Shared responsive deck discovery: full names, leader names/IDs, description previews with full expansion, colours, built/virtual status, legality and useful empty states. Search name, leader and description; combine colour, leader, deck type and rule-readiness filters before browsing. Show at most six choices initially, with an explicit more control. Filtering must never silently replace a selected deck.
- Online Arena: independent filters for your and the opponent's decks; opponent list defaults to ready decks; keep readiness gates, costs, friend modes and the submitted deck/opponent contract. On phones use a native full-screen wizard: Your deck → Opponent → Review and start, with Back/Close, focus handling and safe areas. Desktop keeps an at-a-glance setup.
- Device/local Arena: use the wizard and searchable deck selection over the installed pack, resolve leader metadata correctly, and label missing descriptions honestly. Do not change the offline pack format, disclose private notes, or fetch online data during device setup.
- Deck library: searchable/filterable discovery and visible descriptions; deck details show the saved description near the heading.
- Deck builder and leader drafting chooser: apply card type/colour and game/colour filters in SQL before the result cap; make full names readable and discard stale async results.
- Owned leaders: search names/card numbers/deck descriptions plus set and deck-availability filters; show full names and saved descriptions for linked decks.
- Add a dev-only fixture preview and scenario/browser proof at 390 and 1440 wide, including long names, many decks, no matches, independent filters, lock gating, wizard Back and final submitted values.

## Acceptance
- [ ] Deck library and Arena expose full deck names and description previews/full text, with an explicit missing-description fallback.
- [ ] Your/opponent searches and meaningful filters work independently; six initial choices, more/reset/no-match states; selected IDs survive filtering. Locked opponent decks cannot start a game; Masters-only and ownership scopes remain.
- [ ] Phone setup uses the entire screen with three steps; Back retains selections; only review can submit. Desktop exposes both sides. Friend invitation does not require choosing their deck.
- [ ] Local/device setup uses the same flow without network reads, shows correct leader names/colours and honestly states pack descriptions are unavailable.
- [ ] Deck builder and leader draft searches apply filters before limiting results, preserve the chosen game and ignore stale results.
- [ ] Leaders can be narrowed by text, colour/game, set and deck availability; linked deck descriptions and long names are readable. Deck detail description is prominent.
- [ ] `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`; meaningful browser scenario and before/after shots at 390/1440. No new dependencies or migrations.
