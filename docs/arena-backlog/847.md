## Outcome
Find discoverability problems cheaply, then check understanding with people. Agent completion alone is not a learning success metric.

## Protocol and acceptance
- [ ] Run a fresh context with only URL and goal: “Learn this game from the tutorial, finish a practice match, and explain how charging, attacking, combos and winning work. Report anything you could not infer.” Do not supply source, selectors, curriculum answers or click sequence. Record tool/browser/model/version, viewport, input mode, prior-game-knowledge limitation, elapsed time, action count, stalls, retries and screenshots.
- [ ] Run Luna plus existing browser tools first for low-cost reasoning/control inspection; TinyFish must follow as the second independent hosted-browser evaluation. Luna needs browser tools; TinyFish may use a different model. Compare identical goals and environments, not brand names. Start with 3 independent runs, cap each at 10 minutes / 60 actions and one retry per stuck step; record actual cost when available, do not invent a price or call it a controlled child simulation.
- [ ] Preserve private Site/app access. Use an already authorized test profile or local fixture/browser; report authentication blocks separately. Never make the site public, expose keys in prompts, spend on repeated paid runs automatically or interact with live decks/matches. Paid provider testing needs a configured approved account/budget; this issue can deliver the harness/protocol with an explicit execution blocker if unavailable.
- [ ] Report observed failures versus hypotheses; replay each claimed UI bug deterministically. A failed agent action may be tooling, not UI. Agent reading hidden DOM is not visual evidence. Include a prompt-only copy critique separately from browser evidence.
- [ ] Prepare a 3–5 first-time-player session sheet (child-friendly, observed by an adult where appropriate): no coaching; ask learner to explain energy use, predict a tie, defend by combo, choose next action on a changed board and finish one turn unguided. Record only task outcomes/anonymized notes; no required audio/video recording.
- [ ] Proposed release gate: no blocking control failures; every participant can reach handoff; at least 4/5 concepts independently explained plus a legal unguided turn for at least 80% of participants. Report sample size and unresolved confusion; a small study is directional evidence, not statistical proof. Human testing remains unverified until performed—an agent must not tick it on their behalf.

Haiku/Luna-sized execution/reporting task. No UI fixes here: file reproduced findings as small follow-ups. TinyFish source: https://www.tinyfish.ai/browser .
