Production verification for #793 found that real deck/art downloads succeeded but shell installation failed. The deployed manifest at revision `526e55622e7f6c3da122f2c90b8e3c31eff88e85` included `/_next/static/immutable/chunks/3qp13y3a2zq8a.js.map`, which returned HTTP 403. The other listed assets and shell returned 200.

The shared shell-asset predicate now excludes source maps, and the service worker agrees. The build-time manifest already filters through that predicate, so it omits the debugging file while retaining runtime JS, Worker code, CSS, fonts and icons. Required-asset failures still abort and remove the partial installation; no failure is silently ignored.

The registered shell verification checks a mixed JS/CSS/font/source-map build inventory against both predicates. Existing interrupted-install tests retain the strict failure and old-shell preservation checks. This change contains no UI redesign, database mutation or production-setting change.
