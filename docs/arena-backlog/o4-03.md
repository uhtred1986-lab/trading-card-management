## Acceptance

- [ ] Interrupted or corrupt downloads never appear ready; retry succeeds without overwriting a working version, and missing/unreadable artwork is detected before readiness.
- [ ] A saved match keeps its pinned pack/runtime across an update; failed update and quota errors retain the last usable installation.
- [ ] Every required art resource is decoded/verified in-browser; opaque responses are not treated as checksum-verified merely because Cache.put succeeds. Offline installed assets resolve without network.
- [ ] Run focused scenario checks plus `npm run typecheck`, `npm run lint`, `npm test` and `npm run build` before finalizing code. For documentation-only work, verify commands, links and claims against observed evidence. Engine/rules changes also require reviewed `npm run contract:emit` output and the repository's `npm run arena:fuzz -- 40` gate; database-backed fuzz/live-device/paid checks unavailable to an agent remain explicitly unverified, not silently skipped. Compiler changes require glossary and signed-off readings/gap diffs. Run no live database writer.
- [ ] Attach scenario-specific evidence and limitations per acceptance bullet; preserve online behavior and completed #547 replay work. If an existing correctness issue owns a blocker, link it and leave this issue's affected acceptance open.

## Out of scope

Caching authenticated pages, silently deleting saved-match inputs, cloud sync. No new dependency, production configuration change, live database write or paid-provider call is authorized by this ticket.
