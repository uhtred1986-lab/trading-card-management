Refs #907. BT31-087 Chronoa, God's Power Stolen permits a ≪Saiyan≫ Battle Card with [Over Realm 2] from the Warp, played in Rest Mode, after its printed Leader condition and hand-to-Warp cost. The compiler kept only the family "Over Realm" (`keywords: ["Over Realm"]`), so the selector also accepted [Over Realm 4] cards such as BT31-095.

Done: `CardFilter` gains optional `keywordsExact` / `notKeywordsExact` (printed names from `keywordName`: "Over Realm 2", "Dark Over Realm 2", "Swap 1"). A tag printed with a digit is exact as well as family; a negated one is exact only. The text matcher, the VM matcher, the filter validator (`FILTER_FIELDS`, type `strings`), `describeFilter` and the rules language (filters print as phrases) all carry it. Filters without the field are unchanged and still valid; “[Over Realm]”, “[Blocker]”, “[Double Strike]” stay family-only.

Acceptance:
- [x] Generic parameter-aware keyword target matching; no card-ID branch; family-only selectors keep their reading.
- [x] Printed text → compiled record → stored-row JSON → language round trip → VM: Over Realm 2 Saiyans in own Warp are chosen; Over Realm 4/6, Dark Over Realm 2, non-Saiyans, Extras, opponent Warp, own Drop/hand/Battle Area are refused; Leader condition, hand cost, Rest Mode and the optional choice are kept (`scripts/verify/keyword-param-941.ts`). The Chronoa wording in the test is a reconstruction from the issue, not a fetched card text.
- [ ] Full-catalog before/after comparison: not possible offline. The checked-in fixtures (450 strings with a numbered bracket, 598 skills compiled) contain no filter that prints a numbered keyword apart from Chronoa's shape, so the offline delta is zero. The owner/coordinator should rerun the compile comparison against the live catalog (read only) for any other card whose filter prints `[Over Realm N]`, `[Swap N]`, `[Spirit Boost N]`, `[Z-Stack N]` or `[Empower … N]`.
- [x] Glossary updated (reading rule “A keyword with a number in a target filter”); contract fixture regenerated.
- [x] No dependency, migration, live write or settings change. Compiler-owned stored records for Chronoa still hold the family-only filter until a guarded refresh, which is the coordinator's.
