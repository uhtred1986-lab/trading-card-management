## Build

Add a local storage adapter and versioned record schema for pinned inputs, engine/runtime/policy versions, state/checkpoint, accepted actions, revision and separate game/policy RNG. Commit accepted moves atomically with their checkpoint; validate records on load and preserve the last valid save on failure.
