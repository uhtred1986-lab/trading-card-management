Tracking: #1112. Depends on #1103. Owner, 25 Oct 2026 (comment on #1112): may be done by Claude agents;
no paid generation; cues with no current event are catalogued as unsupported and not wired.

## Outcome

A provider-neutral, versioned prompt catalog covering every sound proposed for the milestone. Shared
base sounds are reused across characters.

## Acceptance

- Every seed cue (36 rows) has: stable cueId, category/event, visual marker, purpose, priority,
  generated duration, playback duration/loop, 2–3 variations, a copyable prompt, exclusions, optional
  character/technique parameters, filename, source preference (CC0/generate/synth), availability
  (missing/candidate/approved), licence provenance fields, trigger/unsupported status and fallback.
- Prompt templates expanded per cue; match stingers are the marked exception to "no music". Voice is a
  separate asset class (#856); no authentic anime-actor audio, no browser TTS, no copyrighted references.
- No API calls; no audition claimed before assets exist. Readable export in `docs/arena-sound-prompts.md`.

## Delivered

`src/lib/arena/immersion/sound-catalog.json` (36 cues, 27 supported, 9 unsupported and unwired),
its type and `validateSoundCatalog` in `sound-catalog.ts` for the #1108 UI, the readable export
`docs/arena-sound-prompts.md`, and the validator run in `scripts/verify/arena-immersion.mts`: catalog
shape, every supported cue maps to a #1103 contract cue and fits its window, every contract cue has a
sound, fallbacks match today's synth tones, and the doc repeats every cue's exact prompt.
