**Source:** `docs/arena-hud-spec.md` §2.2–§2.6 (not built; §1, §1.1 and §2.1 are — see §6); `docs/arena-skin-spec.md` for the paint rules; `src/components/arena/stage/ArenaStage.tsx` and `src/components/arena/shared.tsx`.

**Problem.** Above the hand sit two same-weight bars (narration ribbon and prompt card), a filled *Skip charge* button that looks like the main action, a hint line clipped by the move-count pill, nine equal-weight settings controls, and three dashed empty Battle Area slots. On a 667 px phone the hand — where the answer usually is — gets what is left.

**Build, one commit per section so each can be reviewed on a phone.**
- **§2.2 One card, not two bars.** The ribbon becomes a dim 11.5 px `LAST` line inside the top of the prompt card, one line, its own hairline; the ask keeps the display type. During beat playback the narration *is* the headline and the `LAST` line hides (the `held?.text` branch already does this).
- **§2.3 Filled means do the thing.** One exported predicate beside `shortLabel` in `shared.tsx`: an action that declines, skips, passes, ends or cancels is a ghost — `endMain`, `pass`, `charge` with `card: null`, `block`/`counter` with `card: null`, `optionalCost` with `pay: false`, `choose` with empty `cards`. At most one filled button at a time. Unit-test it against `contract/fixtures/*.json`.
- **§2.4 The hint's line.** Drop the move-count pill from the hint row (it lives in the turn strip); hint wraps to two lines (`line-clamp-2`).
- **§2.5 Demote the settings.** `log` stays inline; the other eight move behind one `⋯` opening the existing `Sheet`, grouped Feel (buzz, sound, pace), Board (staging, skin), Help (report a problem). One 44 px target.
- **§2.6 Reclaim the empty board.** Empty Battle Area collapses to one 30 px line "no Battle Cards yet"; `deck`/`drop` counts move behind the same `⋯`.

**Must not change** (§3): everything about whose move reads `live.waiting`; no colour literals (skins are paint only); `.arena` must not become a stacking context.

**Acceptance.**
- `npm run typecheck && npm run lint && npm test && npm run build`.
- The ghost/filled predicate has a test over every fixture; `auditWhoseMove` still passes in `npm test`.
- Scenario proof: screenshots at 375 px in both skins (`?skin=anime`, `?skin=night`) of a Main Phase prompt, a charge prompt and an empty board, attached to the PR; the hand gains visible height versus `main`.
