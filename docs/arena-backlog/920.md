## Problem and current official errata
Four Universe 3 Battle Cards share an unread destination-replacement Permanent with stale catalog text: DB2-137 Anilaza, the Towering Atrocity; DB2-140 Secret Technique Paparoni; DB2-151 Nigrisshi, from the Shadows; DB2-153 Viara, Everlasting Assault.

> [Permanent] When this card is removed from a Battle Area or Combo Area, it is placed at the bottom of its owner's deck instead.

Owner authorized this shared fix and delegation during the rules review. The coordinator independently verified Bandai’s official errata for all four: this replaces any removal from either named source area, not only moves intended for Drop. The app catalog still contains the obsolete Drop-only text despite has_errata=true. Apply current official wording through the repository canonical errata path and retain a regression against the stale input; do not silently implement the obsolete restriction. All four are currently banned in the catalog; preserve those deck-legality restrictions. This replaces the intended move; it is not a move to Drop followed by a recovery trigger. Inspect existing replacement machinery before adding a capability. No per-card ID overrides.
