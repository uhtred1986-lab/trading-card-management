# S06 / #570 game plan evidence

The board screenshots come from `scripts/arena-gameplan-570.mts`. That script creates a disposable rules-engine game, reaches the Main Phase through legal setup actions, and builds the snapshot and both previews with `EngineAPI` and `previewGameplan`. `PLAN-READY` is a synthetic fixed-price Battle Card in the verification harness; Whis BT1-055 and Senzu Bean BT11-053 are checked local artwork used to show its board and energy positions. The art illustrates the test card and does not claim the printed cards have the synthetic skill. The normal L-RED Leader retains its unrelated Awaken draw skill.

The `before-*` images are from base commit `46bf174`, and the `after-board-*` and `after-plan-*` images are from this branch. Each set contains night and anime skins at 1440×900 and 390×844. The phone and desktop plan images show the authoritative preview sequence: 2/2, 1/2, then 0/2 ready Red energy. The browser script tests real phone touch, 44 px controls, no horizontal overflow at normal and 200% text, keyboard Enter to clear the plan, and confirms the board renders local card artwork.

`scripts/verify/gameplan-570.ts` checks exact coloured budgets, applied energy-rest and source-rest events, clone purity and every offered follow-up on legacy and rules engines. Negative cases cover unavailable actions, a hidden selected-price condition, a reachable rest-triggered draw, Spirit Boost marker payment, copied skills, an activated draw, concealed Counter possession, and opponent Hidden Mode identity metamorphosis. `scripts/verify/arena-gameplan-db.mts` reloads persisted versus rows in PGlite on both engines and checks stale revision, wrong/unseated player, malformed input, terminal status, valid plans, unchanged revision, and full row equality. The Next server action separately checks signed-in ownership and reads only seat metadata before loading a versus game; the PGlite scenario calls its pure service boundary rather than the Next request context. No live database, paid model, device, or production check was run.
