# Arena #561 browser evidence

The browser run is DB-free. `scripts/verify/ability-engine-fixture-561.ts` builds DBS states, moves, legal actions, availability rows and Snapshots with EngineAPI. The verified printed card facts used for the in-memory fixture definitions are Senzu Bean BT11-053 (Blue EXTRA, cost one total energy with one Blue specified, no power/combo stats) and Whis's Coercion BT1-055 (Blue EXTRA, cost one total energy with one Blue specified, no power/combo stats). The Senzu artwork is the checked-in BT11-053 asset from #546; Whis uses the checked-in BT1-055 asset. Fixture definitions are restored after the run.

The preview route's existing `/api/v1/games/:id` polling is intercepted and fed the generated Snapshot. For Senzu, revision 1 starts at an actual Counter: Attack decision and revision 2 updates that same open viewer to the defender combo decision. The Whis browser case starts at a real Counter: Attack response. No gameplay availability, timing, legal action, price, or Snapshot row is authored by the browser harness.

On phone, the harness uses real upward/downward touch swipes to place the complete offer inside the sheet's clipped scrollport, verifies the fixed close control remains visible, tabs to the Activate button, then taps it. It compares the callback action byte-for-byte with the current EngineAPI legal action and applies that action to a cloned engine state to assert payment, movement, emitted events and effect continuation. Senzu rests exactly the one active Blue energy and opens its card-choice prompt. Whis rests exactly the one active Blue energy, moves to Drop, and emits skill plus attack-negated events. HTTP transport and the preview action response are mocked; the captured actions and resulting state transitions are EngineAPI-owned.

The run covers both `anime` and `night` skins at phone (390×844), desktop (1440×900), short phone (390×650) and narrow phone (320×568). The phone run checks opening live review, a phase/revision refresh while it stays open, the full-art `Abilities now (1)` control, previous/next full-art navigation, reduced motion, 200% text horizontal overflow, and the current Activate CTA fully inside the scrollport after touch scrolling. Screenshots include the 1440/390 actual-art views in both skins and short/narrow-phone 200% text views.

Reproduce with `DATABASE_URL='' npm run dev -- --port 3019` and `DATABASE_URL='' npx tsx scripts/arena-abilities-now-561.mts --base=http://localhost:3019`.
