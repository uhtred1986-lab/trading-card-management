# Return only the original successful Warp arrival

R-498 admits the exact delayed return tails of BT13-135 #20 and BT14-141 #10. The full frozen 6,597-card / 13,966-record census changes only those two records' ops, unread, pattern and reads. Printed text, price, conditions, triggers, usage and validity are unchanged. There are 13,016 readable records and 950 unread. Snapshot SHA-256: `addfdbed242db24c9c4ac67830ca8ff6018ab19043d02915dbc30712156c4090`; recovery/delayed-warp-full-diff.json records the comparison. This is record admission, not an assertion that every other rules-engine limitation on these cards has been eliminated.

The previous generic play parser did not remove the owner destination before the negation suffix in “play any cards sent to a Warp by this skill to their owners' Battle Areas with their skills negated for the turn.” Both tails stayed unread; Dragon Quake retained only a partial delayed Drop branch. The new recognizer requires that exact tail, optional exact fifteen-card replacement clause, and the represented adjacent optional-one opposing Battle choice/Warp move with its exact filter. It does not widen the generic owner-play grammar or admit arbitrary sent-card tails.

An existing authoritative movement-completion receipt now guards scheduling immediately after the choice/move. A named arrival records the destination epoch. The delay directly uses that stamped Warp selector for play, or for Dragon Quake's alternative Drop. This avoids a new delayed choice variable losing the occurrence binding. A failed original move, or a replacement even into the same Warp, schedules no return. A card that leaves and reenters Warp is a different occurrence. Existing beforeTriggers play negation suppresses arrival Autos; no separate preapplied negation is introduced.

The new typed selector flag `requiredStamp: true` is only valid with a nonempty fromVar and without special. Its language flag round-trips through parser/printer, schema, blocks field mapping and generated reference. Runtime validates a complete one-to-one set of unique card IDs and canonical safe nonnegative epoch stamps. It parses the final @ separator, so instance IDs containing @ are not confused by prefix matching. Missing/malformed stamps, bad current chronology and invalid selector combinations refuse explicitly before special-selector early exits. A legitimately missing card or a later occurrence yields no target. The existing optional stamp behavior of other selectors is unchanged. No flow, host, play or VM delayed-effect writer changes were needed; script.ts changes only the Selector interface field.

The complete fixture contains both cards, all frozen records and their own FAQs. Supreme Kai's FAQ requires either player's own Warp to have three cards; two plus one is insufficient. Dragon Quake's FAQ says sixteen cards at activation and fifteen at end means no play. The compiler retains that threshold inside the delayed if/else, with both branches using the same stamped original Warp occurrence. Source departure does not cancel the delayed effect (RM9-3-1); physical ownership determines the destination. RM1-7-2-1-1,9-2-1-3 and3-1-4 support timing and occurrence binding.

`delayed-warp-5` passes 143 cases. Initial boards/resources are staged; activations, payments, attacks, Counter selections, choices and turn endings use JSON-saved RULES.apply. Every action runs both board views and verifies input immutability; this demonstrates view execution/nonmutation, not a separate redaction audit of private payloads. Saved end-turn replay is deterministic. Ordinary source/target movements used to arrange ABA, source departure and owner/controller differences are explicitly native-zone mechanism staging.

Both seats cover actual Supreme Kai Counter Attack play, ordinary-play rejection, black/nonblack Leader, all combinations of own Warp0/2/3 and opponent Warp0/1/3 at one Energy, and paid three-Energy Counter controls. Dragon Quake runs actual Main and Battle activations, paid one Energy, shared Limit across copies and reset on the next turn, wrong Leader, zero choice, Barrier/Indestructible, and target cost equal to or greater than opponent Energy. Its end-turn condition covers15→15,15→16,16→15 and16→16. Normal return, target departure, target ABA, source departure and physical-owner differences are checked; returned cards' printed played Autos remain suppressed.

Typed native replaceLeave mechanism fixtures replace the original Warp with Hand or the SAME Warp; a prohibition fixture prevents it. All schedule zero returns, even if the target later reaches Warp independently. Native Ghost Token creation and valid Z-Deck/paid playZ followed by Supreme Kai removal both redirect to Removed and schedule nothing. Using Kai avoids Dragon Quake's cost filter masking costless token movement. These are native mechanism fixtures, not invented printed replacement or token-creator card claims.

Real before/after skill Counter windows are exercised with clearly labeled mechanism Counter cards. Before the return, a Counter sends the Warp target to Hand and back; the original delayed selector refuses that new occurrence. After the return, a Counter sends the already-returned card to Warp and it stays there. There is no extra choose→play variable to outlive the stamp. Both play and Drop delayed branches reject eleven saved stamp/variable/chronology faults per seat. Schema rejects flag-without-fromVar, empty binding, special combination and false flag; runtime rejects the illegal special combination and safely ignores a missing card instance. A valid instance ID containing multiple @ separators resolves against its exact stamp. Unsupported cardinality, duration, destination and timing variants retain unread clauses.
