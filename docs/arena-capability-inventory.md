# Arena capability and test-gap inventory

Generated by `scripts/verify/capabilities.mts` from structured metadata and checked against current verifier callsites and VM source sites.

A status applies only to the named behavior and proof below. **Supported** means that exact runtime scenario has a positive assertion; it does not imply exhaustive rules coverage. **Unsupported** means the named scenario is deliberately not asserted on the rules engine. **Untested** means there is no runtime assertion in the cited lane. For the #459 and #118 test-lane rows, untested describes that test lane, not the gameplay mechanics. Declaration checks, hook contracts, and corpus counts are not runtime proof. This inventory uses only local source and test fixtures; it does not query the card database.

## Evidence limits and independent work

- There are 17 hook points in the declarative contract. Their declarations and the Stage 3 #170/#135/#137 exit checks establish language/declaration shape, not that every printed mechanic executes correctly. The delivery plan records #170 as closed after declaration checks; it also records native `mill` as the one macro exception.
